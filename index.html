Salvar automático no GitHub

Cada registro vai sozinho para um repositório privado seu, com o histórico de todas as versões. Funciona também em outro celular ou no PC.

Como criar o repositório e o token
  1. No GitHub, crie um repositório privado, por exemplo balanca-dados, marcando Add a README file.
  2. Vá em Settings › Developer settings › Personal access tokens › Fine-grained tokens e toque em Generate new token.
  3. Em Repository access, escolha Only select repositories e marque só esse repositório.
  4. Nas permissões do repositório, dê a Contents o acesso Read and write.
  5. Gere o token, copie e cole aqui. Ele fica salvo só neste aparelho.
